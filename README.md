# Crown Detail Hub

Mobile-first landing page for Crown Detail Hub, a premium auto detailing and car care business in Surrey, British Columbia.

## GitHub Pages

1. Create a new public GitHub repository.
2. Upload all files and the complete `assets` folder from this package.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site uses plain HTML and CSS, so no installation or build command is required.

## Local preview

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
