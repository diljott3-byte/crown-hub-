# Crown Detail Hub — Static Website

This is a plain HTML/CSS/JavaScript website designed for GitHub Pages.

## Upload to GitHub

1. Create a new public GitHub repository.
2. Upload everything inside this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

No npm install, build command, React or server is required.

## Main files

- `index.html` — Home
- `services.html` — Services and pricing
- `about.html` — About
- `contact.html` — Contact and directions
- `assets/css/style.css` — Complete design
- `assets/js/main.js` — Lightweight header/video behaviour
- `assets/media/` — Logo, images and hero video
